# Calculadora de capacidad de ahorro · Hábito Financiero

Herramienta gratuita de la Cápsula 1 del *Kit para reducir el estrés financiero*.
Una sola página (HTML + JS, sin dependencias ni llamadas externas): todo se calcula en el navegador y no se guarda ningún dato.

- Capacidad de ahorro mensual y % del ingreso (referencia orientativa: ~20%).
- "Creías gastar X, en realidad gastas Y".
- Simulación de recorte de gastos invisibles, sin rentabilidad.
- Herramienta educativa; no es asesoría financiera personalizada.
